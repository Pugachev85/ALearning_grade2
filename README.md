# 🚀 User Management System - Микросервисное приложение

## 📖 Описание проекта

Микросервисная система управления пользователями, построенная на Spring Boot с использованием современных технологий и шаблонов микросервисной архитектуры.

## 🏗️ Архитектура

Приложение состоит из следующих компонентов:

### 🔧 Основные сервисы
- **👥 User Service** (`user-service`) - Сервис управления пользователями (CRUD операции)
- **📧 Notification Service** (`notification-service`) - Сервис отправки уведомлений

### ⚙️ Инфраструктурные сервисы
- **🚪 API Gateway** (`gateway`) - Единая точка входа для всех запросов
- **🔍 Service Discovery** (`service-discovery`) - Регистрация и обнаружение сервисов (Eureka)
- **⚙️ Config Server** (`config-server`) - Централизованное управление конфигурацией

### 🔗 Внешние зависимости
- **🐘 PostgreSQL** - Реляционная база данных
- **🚀 Apache Kafka** - Брокер сообщений для асинхронной коммуникации
- **🦓 ZooKeeper** - Координация кластера Kafka

## Подробное описание компонентов

### User Service (`user-service`)
Сервис управления пользователями с полным CRUD функционалом:

#### Основные возможности
- Создание, чтение, обновление, удаление пользователей
- Валидация данных пользователя
- Веб-интерфейс на Thymeleaf
- REST API для интеграций

#### Ключевые компоненты
- `UserController` - Веб-контроллер для Thymeleaf интерфейса
- `UserApiController` - REST API контроллер
- `UserServiceImpl` - Бизнес-логика управления пользователями
- `UserRepository` - Доступ к данным через JPA

#### Особенности
- Интеграция с Kafka для отправки событий
- Circuit breaker для устойчивости к сбоям БД
- Валидация через Bean Validation

### Notification Service (`notification-service`)
Сервис обработки уведомлений:

#### Основные возможности
- Обработка событий пользователей из Kafka
- Отправка email-уведомлений
- Поддержка различных типов событий (создание, удаление)

#### Ключевые компоненты
- `UserEventListener` - Слушатель Kafka сообщений
- `NotificationServiceImpl` - Логика обработки уведомлений
- `EmailService` - Абстракция для отправки email

#### Особенности
- Асинхронная обработка через Kafka
- Заглушка для email отправки (логирование вместо реальной отправки)
- Resilience4j для устойчивости

### API Gateway (`gateway`)
Единая точка входа с функциями маршрутизации:

#### Функциональность
- Маршрутизация запросов к соответствующим сервисам
- Балансировка нагрузки через Eureka
- Retry механизмы для устойчивости
- Fallback обработчики

### Config Server (`config-server`)
Централизованное управление конфигурацией:

#### Особенности
- Хранение конфигураций в файловой системе
- Поддержка профилей (development, production)
- Автоматическое обновление конфигураций

### Service Discovery (`service-discovery`)
Регистрация и обнаружение сервисов через Eureka:

#### Функции
- Регистрация всех микросервисов
- Health check мониторинг
- Балансировка нагрузки на клиентской стороне

## 💻 Работа с приложением

### 🌐 Веб-интерфейс
Доступен по адресу: http://localhost:8081/users

**Функциональность:**
- 👁️ Просмотр списка пользователей
- ➕ Создание новых пользователей
- ✏️ Редактирование существующих пользователей
- 🗑️ Удаление пользователей

### 🔌 REST API
Базовые эндпоинты через Gateway:

```bash
# Получить всех пользователей
curl http://localhost:8080/api/users

# Создать пользователя
curl -X POST http://localhost:8080/api/users \
  -H 'Content-Type: application/json' \
  -d '{"name":"Test User","email":"test@test.com","age":25}'

# Получить пользователя по ID
curl http://localhost:8080/api/users/1

# Обновить пользователя
curl -X PUT http://localhost:8080/api/users/1 \
  -H 'Content-Type: application/json' \
  -d '{"name":"Updated Name","email":"updated@test.com","age":30}'

# Удалить пользователя
curl -X DELETE http://localhost:8080/api/users/1
```

| Инструмент | Назначение |
|------------|------------|
| 🌐 Eureka Dashboard | Просмотр зарегистрированных сервисов и их статуса |
| 📊 Kafka UI | Мониторинг топиков и сообщений Kafka |
| ⚙️ Config Server | Просмотр конфигураций сервисов |

### Config Server endpoints

## 💫 Особенности реализации

### 🔄 Асинхронная коммуникация
- 📨 **События пользователей**: Отправляются в Kafka топики
- ⚡ **Асинхронная обработка**: Notification Service обрабатывает события независимо
- ✅ **Гарантированная доставка**: Надежная передача сообщений через Kafka

### 🛡️ Устойчивость к сбоям
- 🔌 **Circuit breaker**: Защита операций с базой данных
- 🔄 **Retry механизмы**: Повторные попытки при временных сбоях
- 🪂 **Fallback обработчики**: Graceful degradation при отказах

### 📊 Мониторинг здоровья
- 📈 **Spring Boot Actuator**: Мониторинг эндпоинтов
- ❤️ **Health checks**: Проверка состояния всех зависимостей
- 📊 **Метрики Circuit breaker**: Статистика работы механизмов устойчивости

### 🔒 Безопасность
- ✅ **Валидация входных данных**: Проверка корректности пользовательского ввода
- 🛡️ **Защита от SQL injection**: Использование JPA для безопасных запросов
- 📧 **Валидация email форматов**: Проверка корректности email адресов
